Versão atual:
🗂️ Formato de armazenamento
Reestrutura o JSON gravado na planilha para um formato mais organizado: separa configurações e brincadeiras do perfil, e transforma ganhos/despesas agrupados por mês em listas simples com campo de data. A leitura entende os dois formatos sempre, em qualquer dispositivo — pode ativar sem pressa, e desativar a qualquer momento sem perder nada.
Gravar no formato novo (schema v1)
Ao ligar, os próximos envios já usam o formato novo. Nada muda de imediato — só quando houver a próxima gravação.
🔒 Encriptação dos dados sincronizados
Encriptar antes de enviar à nuvem
Cifra o JSON (AES-GCM 256 bits) antes de gravar na planilha. Quem tiver acesso à célula só vê texto ilegível — só decifra com a senha certa. Feature de teste de segurança.
Desbloquear com digital / Face ID
Guarda a senha protegida pela biometria deste aparelho, para não precisar de digitá-la sempre. A senha continua a ser a chave real — a biometria só desbloqueia o acesso a ela localmente.
Este dispositivo ou navegador não suporta desbloqueio biométrico.
Pedir confirmação a cada sincronização
Se ativado, o app sempre pede senha ou biometria antes de decifrar, mesmo já sabendo a senha. Se desativado, decifra automaticamente em segundo plano usando a senha já guardada neste aparelho.
🔗 Migrar planilha
Cole a URL de uma nova planilha e envie. A URL é gravada uma única vez na planilha atual — qualquer dispositivo que sincronizar com ela (incluindo este) muda sozinho para a nova.
📋 Log de sincronização
Últimos eventos de sincronização (sucesso, erro, tempo esgotado) — útil para perceber se um problema é do app, da rede, ou da planilha estar lenta.
👻 Brincadeira secreta
Desativada por padrão. Uma tela cômica de "hackeamento" que pode aparecer raramente ao abrir o app — só para o perfil com um nome específico, e só depois de ativada aqui. Sincronizado via nuvem.
Ativada
Desligada por padrão em todos os dispositivos novos. Uma vez desligada de novo, para de aparecer em todos os dispositivos sincronizados.
🎂 Mensagem de aniversário
Desativada por padrão — só aparece depois de configurar uma data abaixo. Aparece automaticamente nesse dia, com confetes e o nome atual do perfil. Sincronizado via nuvem.
📊 Resumo de ontem
Mostra o resumo do dia anterior na próxima abertura, mesmo que o interruptor esteja desligado ou o resumo já tenha sido mostrado hoje. Usa km e turno se estiverem ativos.
